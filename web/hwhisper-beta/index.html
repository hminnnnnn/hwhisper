이게 뭔가요

말하면, 정리해서, 그 자리에

전역 단축키를 누르고 말하면 기기 안에서 한국어·영어를 받아쓰고, 원하면 무료 LLM이 필러를 지우고 문장을 다듬어 지금 커서가 있는 앱에 바로 입력합니다. Wispr Flow·Typeless의 무료·로컬 대체재예요.

설치 방법

4단계면 끝나요

  1. DMG를 열고 앱을 옮기기
    받은 .dmg를 더블클릭해 열고, Hwhisper.app을 응용 프로그램 폴더로 드래그하세요.
  2. 첫 실행 차단 해제 (공증 안 된 무료 배포라 1회만)
    터미널에 아래 한 줄을 붙여넣고 실행하세요. 또는 시스템 설정 › 개인정보 보호 및 보안 맨 아래 “확인 없이 열기”를 눌러도 됩니다.
    xattr -dr com.apple.quarantine /Applications/Hwhisper.app
  3. 권한 허용
    앱을 실행하면 마이크, 손쉬운 사용, 입력 모니터링 권한을 요청해요. 받아쓰기와 커서 삽입에 필요하니 모두 허용해 주세요.
  4. 말하기
    기본 단축키 오른쪽 ⌘(설정에서 변경 가능)를 짧게 탭 → 말하고 → 다시 탭. 정리된 텍스트가 커서 위치에 입력됩니다.

문장 다듬기 (선택)

키 없이도 바로 써요

키 없이 설치하면 받아쓴 원문이 그대로 입력됩니다. 무료 Gemini·Groq API 키를 넣으면 필러 제거·문장부호 교정·목록 정리까지 해줘요. 첫 실행 온보딩에서 발급 링크와 연결 테스트를 안내합니다.

프라이버시

음성은 기기 밖으로 나가지 않습니다. 받아쓰기는 온디바이스로 처리돼요. 문장 다듬기를 켠 경우에도 전사된 텍스트만 선택한 제공자로 전송되며 음성은 전송되지 않습니다. 로그에는 전사 본문 없이 글자 수만 남습니다.
